
# Phím tắt Windows 11 dành cho sinh viên

Tài liệu tham khảo nhanh giúp sinh viên thực hiện các thao tác thông dụng trên Windows 11 mà không cần tìm kiếm trong nhiều menu.

## 10 phím tắt hữu ích

| Phím tắt | Chức năng |
|---|---|
| Ctrl + C | Sao chép |
| Ctrl + V | Dán |
| Ctrl + Z | Hoàn tác |
| Ctrl + F | Tìm kiếm nội dung |
| Windows + E | Mở File Explorer |
| Windows + I | Mở Cài đặt |
| Alt + Tab | Chuyển cửa sổ |
| Windows + D | Hiện Desktop |
| Windows + Shift + S | Chụp một vùng màn hình |
| Ctrl + Shift + Esc | Mở Task Manager |

## Ví dụ sử dụng

Khi làm báo cáo, bạn có thể dùng Windows + E để mở thư mục tài liệu, Alt + Tab để chuyển giữa Word và trình duyệt, sau đó dùng Windows + Shift + S để chụp kết quả thực hành.

Lưu ý: Một số tổ hợp phím có thể khác nhau tùy ứng dụng hoặc cài đặt của thiết bị.
